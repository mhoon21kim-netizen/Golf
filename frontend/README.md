# 프론트엔드

Next.js 기반 골프 코치 프론트엔드

## 설치

```bash
npm install
```

## 실행

### 개발 모드
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
npm start
```

기본 포트: 3000

## 환경 변수

`.env.local` 파일 생성:

```
NEXT_PUBLIC_API_URL=http://localhost:3001
```

## 주요 기능

- 단계별 커리큘럼 (Lv1~Lv3)
- 영상 업로드 및 분석
- 판정 결과 표시
- Day Sheet 기록
- 진행 상황 추적

## 기술 스택

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
